REST API

Az alkalmazás egy RESTful API-n keresztül JSON formában teszi elérhetővé a pizza tábla adatait. Az API-t cURL-lel és Postman-nel teszteltük.

Alap cím: http://localhost:8080/api/pizzak

MetódusCímLeírás
GET/api/pizzakAz összes pizza
GET/api/pizzak/{nev}Egy pizza adatai (ha nincs: 404)
POST/api/pizzakÚj pizza felvétele (201)
PUT/api/pizzak/{nev}Pizza módosítása
DELETE/api/pizzak/{nev}Pizza törlése (204)

Tesztelés cURL-lel
